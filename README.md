# Enterprise Network Configuration & Troubleshooting Lab

## Project Overview
This project simulates a multi-department enterprise network using Cisco Packet Tracer. It demonstrates network segmentation, IP addressing, routing configuration and connectivity testing across different departments.

## Network Architecture
The simulated network consists of:
- One Cisco 2911 Router
- One Cisco 2960 Switch
- Four End Devices (PCs)
- One Server
- Two VLANs: VLAN 10 (IT) and VLAN 20 (HR)

## Technical Implementation
- Configured VLAN segmentation to separate departmental networks.
- Implemented IP addressing and subnetting for both VLANs.
- Configured router subinterfaces for inter-VLAN routing.
- Configured switch trunking to carry traffic between VLANs.
- Configured DHCP and tested automatic IP allocation (if implemented).

## Troubleshooting & Testing
- Tested connectivity between devices within the same VLAN.
- Verified gateway connectivity.
- Tested communication between different VLANs.
- Investigated and resolved network connectivity issues.

## Tools & Technologies
Cisco Packet Tracer, TCP/IP, VLAN, DHCP, Routing, Switching, Subnetting.
